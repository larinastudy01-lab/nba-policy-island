# NBA 政策島｜美國客場巡迴

以美國本土 48 州地圖探索 NBA 球隊站點的原生前端專案。第一版開放金州勇士站，預設展示進行中的模擬賽事。

線上網站：[開啟 NBA 政策島｜美國客場巡迴](https://larinastudy01-lab.github.io/nba-policy-island/)

## 本機開啟

直接以瀏覽器開啟 `index.html`，無須安裝套件、啟動伺服器或提供 API Key。

在 VS Code 的檔案總管右鍵 `index.html` →「在檔案總管中顯示」，再雙擊檔案即可。

## 功能

- 美國本土 48 州本地 SVG 地圖，勇士站依舊金山灣區座標定位。
- 藍金籃球按鈕支援滑鼠、觸控、Tab、Enter、Space，資訊卡支援 Escape 收合。
- 「模擬賽事」可切換今日無賽事、尚未開打、比賽進行中及比賽結束。
- 地圖記分牌與站點資訊卡共用同一份資料；僅進行中狀態啟用脈動光暈。
- 桌機資訊卡位於地圖旁，手機改為地圖下方；支援 `prefers-reduced-motion`。
- 所有賽事及比分皆為本地模擬資料，非 NBA 即時資訊；時間以台灣時間（UTC+8）表示。
- 勇士站提供「熱門對戰，門票該怎麼分？」自訂政策挑戰，可試算三種售票方案、並排比較並確認決策。
- 政策選擇與賽況分別管理；確認決策後，地圖與球場顯示獨立的完成進度，並以 `localStorage` 保存。

## 勇士站政策挑戰

玩家扮演主場營運人員，分配 60 張門票。20 名學生各有 30 點預算，60 名一般球迷都付得起原價 45 點，每人最多一張票。以下為自訂模擬，並非 NBA 或球隊實際政策。

| 方案 | 學生入場 | 一般球迷入場 | 總入場 | 收入 | 同時達成兩項目標 |
| --- | ---: | ---: | ---: | ---: | --- |
| 原價售票 | 0 人 | 60 人 | 60 人 | 2,700 點 | 否 |
| 學生保留席 | 20 人 | 40 人 | 60 人 | 2,400 點 | 是 |
| 全場降價抽籤 | 平均 15 人 | 平均 45 人 | 60 人 | 1,800 點 | 否 |

兩項目標為「至少 15 名學生入場」與「收入至少 2,000 點」。抽籤方案採 80 人同池、等機率、不重複抽出 60 人，每人中籤機率為 75%；各組人數為期望值，單次抽籤不保證正好 15 名學生。

「完成」表示已試算並確認一項決策，與「兩項目標皆通過」分開標示。可以確認任一方案，再重新試算其他方案；重新試算或切換賽況均不清除已完成進度。重新整理時會還原已確認的方案、結果與完成標記。

進度儲存在 `nba-policy-island:policy-progress:v1`，僅記錄版本、關卡、站點及已確認方案。不同瀏覽器或來源（本機檔案與 GitHub Pages）各自保存。若環境拒絕讀寫 `localStorage`，頁面會提示，仍可完成本次頁面中的操作。

## 終端機測試

只需既有 Node.js，無須安裝套件或啟動瀏覽器：

```powershell
node --check script.js
node --check tests/policy.test.cjs
node --test tests/policy.test.cjs
```

測試包括三方案的精確結果、唯一達標方案、抽籤期望值、不可超售、改選後失效的舊結果、確認與重試、儲存還原、無效及不可用儲存、四種賽況的實際事件處理器，以及相對路徑與頁內錨點。DOM 部分使用輕量事件替身，不代表已驗證瀏覽器排版或原生鍵盤行為。

## 手動預覽驗收

1. 直接開啟 `index.html`，確認美國地圖、勇士球場、預設 LIVE 及記分牌仍正常。從資訊卡按「進入政策挑戰」，確認跳至同頁關卡。
2. 分別選三方案並按「試算」，對照上表。檢查抽籤的「平均／期望值」、單次不保證人數的說明、兩項目標與一句話取捨。
3. 桌機檢查三方案並排；將視窗縮至 320、375、768 像素附近，確認手機單欄卡片、指標與按鈕可完整閱讀，沒有水平溢出。另檢查 200% 頁面縮放。
4. 用 Tab 導覽、方向鍵與 Space 切換單選方案、Enter 啟動按鈕，確認焦點外框清楚；試算後焦點到結果標題，重新試算後回到所選方案。
5. 以學生保留席試算並確認決策，再按「回到地圖」。確認「已完成 1／1 個政策挑戰」與籃球旁的金色勾號；切換全部四種賽況，確認勾號與政策結果不變，且只有 LIVE 脈動，切至完賽則保留 108：101 並停止脈動。
6. 重新整理相同網址，確認完成進度與已確認方案仍在。重新試算其他方案，確認完成標記持續存在；改選後須重新試算，避免確認上一方案的結果。
7. 在系統啟用「減少動態效果」後，確認 LIVE 動畫停止，靜態光圈、LIVE 文字與政策完成勾號仍可辨認。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 繁體中文頁面與無障礙結構 |
| `style.css` | 深色版面、響應式配置與動畫 |
| `script.js` | 站點與賽事資料、政策計算、事件綁定、進度儲存 |
| `tests/policy.test.cjs` | Node 原生政策計算、儲存與事件替身測試 |
| `assets/us-map.svg` | 可離線使用的美國 48 州地圖 |
| `assets/README.md` | 地圖資料來源與投影說明 |
| `assets/us-states.source.json` | 原始州界資料備份 |
| `.nojekyll` | 讓 GitHub Pages 直接提供靜態檔案 |

## GitHub Pages

此專案可直接由 GitHub Pages 發佈。儲存庫設定使用 **Settings → Pages → Deploy from a branch → main → / (root)**，不需建置流程。

後續修改檔案並推送至 `main` 後，GitHub Pages 會更新網站。

## 後續擴充

站點名稱、座標與四種模擬情境集中在 `script.js` 的 `TOUR_DATA`；政策參數集中在 `POLICY_CHALLENGE`，計算由 `calculatePolicy()` 處理。目前僅開放勇士站政策挑戰，尚未整合 W12 觀賽購物車。

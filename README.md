## 我的球迷、主場尋星與合影冊

島圖工具列的「我的球迷」保留暱稱、膚色、髮型／髮色、表情、球鞋與配件預覽。16 隊球衣及背號欄位保留舊設定，像素玩家此版穿中性運動服，尚未套入各隊球衣。編輯、隨機、重設只影響預覽，**按儲存才套用**到島圖「我」、新照片與單機結算。桌機為側邊試衣間，手機為全螢幕原生 dialog；角色同步至真人房間尚未開放。

點選 NBA 主場後按「尋找球星」，先探索球館合影點，再點球星進入拍照。16 站各有一位代表球星與原創本地插畫／場館。統一標示「代表球星・隊史球星致敬（非現役名單）」；場館為遊戲內自訂設計。

拍照可選站姿／舉球，一般合影隨時開放。夜場燈光只對模擬 LIVE 的主隊開放：勇士客場打湖人時，湖人可選夜場、勇士仍可拍一般合影。定格後可重拍、收藏或下載 960 × 640 PNG，包含角色、球星、背景、暱稱、隊名、場館及日期。

合影冊分成「主場／偶遇」兩頁：主場依不同場館 arenaId 計數，偶遇依不同球星計數，兩頁各為 0／16 起算。同一位球星的兩類照片可以並存，各類重拍才更新對應收藏。保存拍攝當時的造型、姿勢、背景及日期，換裝不改動舊照片。localStorage 只存重建資料，不存大型圖片；不支援儲存時顯示提示，本次頁面仍可使用和下載。PNG 用不含外部圖片的 SVG 轉 Canvas，無須讀取 file:// 圖片到 Canvas，兼容本機與 GitHub Pages 子路徑。

沿用 `nba-policy-island:photos:v1` 儲存鍵，舊版 v1 收藏自動讀入「主場」；下次收藏寫入同鍵的 v2 容器，分開保存主場與偶遇。既有球迷造型與勇士政策完成紀錄保留。

## 島上偶遇與本機測試日期

「島上偶遇」清單提供西岸碼頭步道、中央廣場、五大湖畔公園。每天依 **Asia/Taipei 台灣日期**，安排一位已開放球隊代表球星在其中一處。同日重新整理不變，跨日更新；目前每連續 16 天涵蓋全部球星，每 48 天涵蓋每位球星的三處地點。日期變更每 30 秒檢查，也在頁面恢復時檢查；不受模擬賽況影響。

先點地圖或清單前往地點，當天所在處才顯示「附近有熟悉的身影」。點剪影揭曉後可「一起拍照」，使用已儲存造型及該地點背景。其他地點仍可探索，主場固定合影點始終開放。舊偶遇照片不會因隔天輪替而消失。

本機 `file://` 或 localhost 預覽會顯示日期測試表單，可指定日期並按「套用測試日期」，或在本機網址加上 `?encounterDate=2026-01-01`。1 月 1 日：西岸碼頭步道／柯瑞；1 月 2 日：中央廣場／魔術強森；1 月 3 日：五大湖畔公園／保羅。按「回到台灣今天」清除測試。公開 GitHub Pages 一律忽略測試參數，使用台灣當日日期。

詳細操作、16 站對應與手動驗收：[docs/FAN_GUIDE.md](./docs/FAN_GUIDE.md)。

## NBA 模擬與政策關卡

四種模擬情境套用至八場本地示範對戰，並非即時 NBA 資料。每場只有一份主客隊與比分資料，兩隊面板共用；只有進行中的主隊球館發光，完賽則關燈並保留最終比分。支援 `prefers-reduced-motion` 靜態光圈。

指定示範為**勇士客場打湖人**：LIVE 湖人 74：78 勇士（第 3 節），只亮湖人球館；完賽湖人 101：108 勇士。其他七場的主場仍依各自賽況亮燈。地圖下緣與側欄共用記分板，待開打時間使用 `<time datetime="11:00">`，時區標示台灣 UTC+8。

勇士主場面板內保留「熱門對戰，門票該怎麼分？」：

| 方案 | 學生 | 一般球迷 | 收入 | 兩項皆達標 |
| --- | ---: | ---: | ---: | --- |
| 原價售票 | 0 人 | 60 人 | 2,700 點 | 否 |
| 學生保留席 | 20 人 | 40 人 | 2,400 點 | 是 |
| 全場降價抽籤 | 平均 15 人 | 平均 45 人 | 1,800 點 | 否 |

抽籤為期望值，單次不保證 15 位學生。確認任一已試算的決策即記錄完成，是否達標分開顯示。保留原本 `nba-policy-island:policy-progress:v1` 儲存鍵，舊版完成進度可直接沿用；切換 NBA 賽況、球隊或公共球場均不清除政策進度。

「門票怎麼分？」開啟政策面板；三方案使用同組 radio。試算後以表格比較並標出本次方案，手機改為卡片排列。換方案後須重新試算；「重設」清空本次 radio、結果及比較，不清除已完成紀錄。

## 好友 PK（尚待連線驗證）

目前 `assets/supabase-config.js` 留空，開房／加入停用，沒有網路請求、假房間或假玩家。保留邀請、就緒、共同倒數、結果與重開流程，每局增加 `game_id`、`game_seed`、`round`、`starts_at` 與結構化結果。題目依種子與題號產生，雙方條件相同；各遊戲使用對應比較規則。

`supabase/games-v2.sql` 是供你手動套用的增量，須先有原 `schema.sql`。它包含本人結果提交、局數／遊戲／種子校驗、兩人房間與猜招封存。猜招招式表不開放直接讀取，只有雙方都選定或該回合到期才由 RPC 揭曉；晚交不能改舊回合。前端先確認 v2 能力，舊後端未升級時不啟用專屬遊戲 PK。此次沒有套用 SQL 或更改設定。

完整設定、兩台裝置與權限驗收：[docs/MULTIPLAYER.md](./docs/MULTIPLAYER.md)。

## 手動預覽

1. 自行以瀏覽器開啟 `index.html`。檢查整座島四面環海、球館屋頂與露天球場不同，地標與點擊區隨視窗及 200% 縮放保持對齊。
2. 點「看 NBA」「找人 PK」及「島上偶遇」分類，操作 16 隊、15 球場與 3 地點。用 Tab、Enter／Space 選地標，並用手機的分類清單選取。檢查西岸／沙漠／高地／五大湖／東岸街區、桌機側欄與手機下方面板在 320、375、768、1440 像素附近沒有遮擋或水平溢出。
3. 在勇士與湖人之間切換，確認都是湖人主隊、勇士客隊，LIVE 只有本場湖人主場亮燈；切完賽保留湖人 101：108 勇士並關燈。啟用系統減少動態效果後，確認靜態光圈仍清楚。
4. 打開勇士「門票怎麼分？」，對照上表試算、換方案、重設、確認、回到島圖並重新整理。檢查表格選中強調、手機卡片、既有進度與完成勾號；切球隊、公共球場或模擬狀態不能清除它。
5. 先測潮汐一號投籃、榕樹繞樁、中央草地電腦猜招、霓虹節奏；再依上表測其餘十一場。開始後聚焦投籃區，再用空白鍵出手；也測觸控出手、按住空白鍵、30 秒截止、重開及離場。勾選音效後聽進球／終場聲，再關閉音效確認仍有文字回饋。確認沒有對手或假房間。
6. 尚未配置時確認邀戰按鈕不可用，並閱讀 [兩台裝置邀戰驗證](./docs/MULTIPLAYER.md)。由你手動套用原始＋增量 SQL 與公開設定後，再驗證雙方就緒、勝負、平手、重開、重複加入、第三人、斷線與本人分數權限。
7. 依「我的球迷建立造型並儲存 → 勇士主場尋找柯瑞 → 點合影點 → 拍照收藏 → 下載 PNG → 換裝後從合影冊查看舊照片」操作。確認 PNG 包含全部人物與文字、同隊重拍只計一站，以及照片／政策／賽況三種標記互不影響。
8. 新增八隊各從地圖及清單進場，核對代表球星、隊色與場館。指定本機日期 2026-01-01，在碼頭步道揭曉柯瑞、拍照收藏並下載；在兩個相冊分頁確認勇士主場與柯瑞偶遇照並存。改成 2026-01-02、換裝並重整，舊照片應維持原樣。回今日後檢查正式日期與輪替。

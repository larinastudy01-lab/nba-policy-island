# NBA 政策島

一座原創、四面環海的 2.5D 籃球島。使用原生 HTML、CSS、JavaScript 與本地 SVG，直接開啟 `index.html` 即可離線探索，不需安裝套件。

## 探索內容

- 灣岸區：金州勇士、洛杉磯湖人、洛杉磯快艇。
- 高地區：丹佛金塊、達拉斯獨行俠。
- 都會區：芝加哥公牛、波士頓塞爾提克、紐約尼克。
- 另有港邊、公園、屋頂各 5 座公共球場，共 15 座，與 NBA 球館分別管理。
- 「看 NBA」與「找人 PK」快速入口，23 個可操作地標；分類清單在手機和桌機都可使用。
- 四面海岸、立體球館、露天球線與籃框、碼頭、橋、環島道路、河道、中央廣場與擴建街廓均由本專案繪製。
- NBA 目前開放 8／30 隊，長期全聯盟目標包含多倫多暴龍，目前不擺放未開放球隊的球館。

## NBA 模擬與政策關卡

四種模擬情境套用至四場本地示範對戰，並非即時 NBA 資料。每場只有一份主客隊與比分資料，兩隊面板共用；只有進行中的主隊球館發光，完賽則關燈並保留最終比分。支援 `prefers-reduced-motion` 靜態光圈。

指定示範為**勇士客場打湖人**：LIVE 湖人 74：78 勇士（第 3 節），只亮湖人球館；完賽湖人 101：108 勇士。其他三場的主場仍依各自賽況亮燈。地圖下緣與側欄共用記分板，待開打時間使用 `<time datetime="11:00">`，時區標示台灣 UTC+8。

勇士主場面板內保留「熱門對戰，門票該怎麼分？」：

| 方案 | 學生 | 一般球迷 | 收入 | 兩項皆達標 |
| --- | ---: | ---: | ---: | --- |
| 原價售票 | 0 人 | 60 人 | 2,700 點 | 否 |
| 學生保留席 | 20 人 | 40 人 | 2,400 點 | 是 |
| 全場降價抽籤 | 平均 15 人 | 平均 45 人 | 1,800 點 | 否 |

抽籤為期望值，單次不保證 15 位學生。確認任一已試算的決策即記錄完成，是否達標分開顯示。保留原本 `nba-policy-island:policy-progress:v1` 儲存鍵，舊版完成進度可直接沿用；切換 NBA 賽況、球隊或公共球場均不清除政策進度。

「門票怎麼分？」開啟政策面板；三方案使用同組 radio。試算後以表格比較並標出本次方案，手機改為卡片排列。換方案後須重新試算；「重設」清空本次 radio、結果及比較，不清除已完成紀錄。

## 投籃與真人好友邀戰

15 座球場共用一套 30 秒、每球 1 分的投籃規則。游標在金色區時出手，使用空白鍵或觸控，間隔至少 0.5 秒。單機模式只顯示自己的成績，不產生假玩家。

公共球場可從地圖、分類清單或港邊／公園／屋頂分組下拉選單選取，三者同步。每類有各自場景配色。長按空白鍵的重複事件會被忽略，0 秒停止計分，重開回到 30 秒及 0 分；離開練習或切換場地會清理計時器。

進球及終場音效使用本地 `<audio>` + 原創 WAV，預設關閉。玩家開始操作後勾選「開啟音效」才會播放；瀏覽器拒播時保留分數、文字回饋與提示。原創素材可用 `python assets/generate_audio.py` 重建。

目前 `assets/supabase-config.js` 留空，真人邀戰明確顯示「尚未配置」，開房與加入按鈕停用，且不發出網路請求。已備妥前端流程與可手動套用的 `supabase/schema.sql`；真人同步、SQL 執行、RLS 及並行入房尚待連線驗證。

完整配置、房間規則與兩台裝置驗證：[docs/MULTIPLAYER.md](./docs/MULTIPLAYER.md)。

## 終端機檢查

使用既有 Node.js 與 Python，不需安裝套件，不啟動瀏覽器：

```powershell
node --check script.js
Get-ChildItem assets -Filter *.js | ForEach-Object { node --check $_.FullName }
node --test tests/policy.test.cjs tests/island.test.cjs tests/ui.test.cjs
python tests/check-static.py
git diff --check
```

事件測試使用純 Node 元素替身與虛擬計時；不表示已驗證實際瀏覽器鍵盤、排版、觸控或網路同步。SQL 目前僅做 RPC／權限結構契約檢查，沒有執行於資料庫。

## 手動預覽

1. 自行以瀏覽器開啟 `index.html`。檢查整座島四面環海、球館屋頂與露天球場不同，地標與點擊區隨視窗及 200% 縮放保持對齊。
2. 點「看 NBA」「找人 PK」，操作 8 隊與 15 球場。用 Tab、Enter／Space 選地標，並用手機的分類清單選取。檢查桌機側欄與手機下方面板在 320、375、768、1440 像素附近沒有遮擋或水平溢出。
3. 在勇士與湖人之間切換，確認都是湖人主隊、勇士客隊，LIVE 只有本場湖人主場亮燈；切完賽保留湖人 101：108 勇士並關燈。啟用系統減少動態效果後，確認靜態光圈仍清楚。
4. 打開勇士「門票怎麼分？」，對照上表試算、換方案、重設、確認、回到島圖並重新整理。檢查表格選中強調、手機卡片、既有進度與完成勾號；切球隊、公共球場或模擬狀態不能清除它。
5. 在三種地景的公共球場各試一次單機投籃。開始後聚焦投籃區，再用空白鍵出手；也測觸控出手、按住空白鍵、30 秒截止、重開及離場。勾選音效後聽進球／終場聲，再關閉音效確認仍有文字回饋。確認沒有對手或假房間。
6. 尚未配置時確認邀戰按鈕不可用，並閱讀 [兩台裝置邀戰驗證](./docs/MULTIPLAYER.md)。套用公開設定與 SQL 後，再驗證雙方就緒、勝負、平手、重開、重複加入、第三人、斷線與本人分數權限。

## 擴充

新增 NBA 球隊：在 `TEAMS` 加入 ID、名稱、縮寫、配色與島上 x／y 即可共用地標和面板；沒有對戰資料會顯示無賽事。有新對戰時加入一份 `MATCHES` 主客隊資料，不要為兩隊複製分數。

新增公共球場須同步加入前端 `COURTS` 與 SQL 的允許球場 ID；現有 15 座已一致。公共房、自動配對、W12 購物車及其他球隊政策關卡均尚未開放。

本次只修改工作區檔案與執行終端機檢查，未開啟瀏覽器、推送、部署或套用遠端 SQL。畫面、聲音及兩台裝置同步的驗收須由你手動完成。

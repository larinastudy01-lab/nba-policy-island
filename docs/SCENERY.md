# 美國地標與跑車：本機操作與驗收

本版只修改工作區，沒有開啟瀏覽器、預覽、桌面工具、無頭瀏覽器、截圖、推送或部署，也沒有更動 Supabase。直接手動開啟根目錄 `index.html`，無套件／伺服器需求。全部素材為本專案自行繪製的向量插畫，沒有外部圖片、官方商標圖檔或 CDN。

## 地標資料與操作

「清單 → 美國街景」有 20 站，與 NBA／玩家球場／每日偶遇各用自己的 ID。全島額外保留金門橋和自由女神兩個代表標籤，街區才展開附近名稱；選取與鍵盤聚焦的名稱優先保留。其餘標籤重疊時隱藏，清單仍能查看全部站點。

| 街區 | 地標（景點 ID 去除 `sight-` 前綴） |
| --- | --- |
| 西岸灣區與洛城 | 金門大橋 `golden-gate` ◎、惡魔島 `alcatraz`、九曲花街 `lombard`、好萊塢字牌 `hollywood`、格里菲斯天文台 `griffith`、聖塔莫尼卡碼頭 `santa-monica` ◎ |
| 西南沙地 | 大峽谷 `grand-canyon`、拉斯維加斯歡迎招牌 `vegas` |
| 西部高地 | 紅岩露天劇場 `red-rocks` |
| 中南部 | 重逢塔 `reunion`、阿拉莫 `alamo`、聖路易斯拱門 `gateway-arch` |
| 五大湖岸 | 雲門 `cloud-gate` ◎、威利斯大廈 `willis`、海軍碼頭摩天輪 `navy-pier` |
| 東岸 | 自由女神 `liberty` ◎、布魯克林大橋 `brooklyn`、時代廣場 `times-square`、法尼爾廳 `faneuil` |
| 南端海濱 | 南海灘救生站 `south-beach` |

◎ 為四個可沿路抵達的觀景拍照點。其他 16 處是可眺望的街景：選取只移動鏡頭及查看說明，玩家保持原位，不宣稱已到達。自由女神的步行終點在主島岸邊。

四個觀景點抵達後，按「拍一張旅行照」，可選站姿／舉球、拍照、重拍、下載 PNG 或繼續逛島。使用**已儲存**的造型與拍攝時的日夜背景；PNG 為 960 × 640，向量直接內嵌角色、地標、暱稱、地點及台灣拍攝日期，不會讀取外部圖片。

景點照本版是**下載保存**，不加入合影冊、不寫入主場或偶遇相片資料，也不改動兩冊分母。既有 `fan:v1`、`photos:v1`、政策儲存鍵、球場與房間邀請 ID 均保留。

## 車流、路網與圖層

| 車款 | 位置／行為 | 造型特徵 |
| --- | --- | --- |
| Ferrari F40 紅 | 九曲花街上方觀景鋪面，停放 | 方尾、楔形前端、大尾翼 |
| Ferrari 488 Spider 紅 | 聖塔莫尼卡碼頭旁，停放 | 敞篷座艙、雙座、側進氣口 |
| McLaren 720S 橘 | 灣岸環線，經金門橋車道 | 流線座艙、深色眼窩燈 |
| McLaren P1 銀黑 | 灣岸碼頭展示鋪面，停放 | 水滴座艙、弧形尾燈 |
| Lamborghini Aventador 黃 | 拉斯維加斯街區封閉公路 | 楔形折線、Y 字頭燈 |
| Porsche 911 GT3 RS 白 | 紅岩觀景台，停放 | 圓燈、弧形車尾、高尾翼 |

六款各有獨立的車頭斜視／側面／車尾斜視 SVG，共 18 份。巡遊車依移動方向選圖及左右鏡射；封閉線在轉角取圓弧並減速，頭燈光束跟隨實際路線角度。車影、光束及圖片全部不接收指標事件，景點按鈕另有高層級熱區。

金門橋車道由 `(118,274)` 往 `(343,173)`；南側步道由 `(128,293)` 往 `(353,192)`，端點距車道均超過 18 世界單位。勇士入口 → 北側步道 → 橋東端 → 西側觀景點 → 岸邊步道 → 灣岸碼頭串在玩家路網。一位原有背包路人也沿這條步道折返，不增加真人房間狀態。

車流、路人及玩家共用既有 16ms 迴圈，只有相關街區近景才更新車流。全島留兩個靜態車影；遠離、地圖離開可視區、頁面背景或 `pagehide` 暫停，恢復不追趕隱藏時間。減少動態時顯示靜態車輛。日夜只切照明，模擬完賽只關主場脈動，不會關閉夜間車燈。

新增美術來自 `sights-core.js`、`traffic-core.js`；執行 `node assets/generate_scenery.cjs` 可重建 40 份景點日／夜 SVG、18 份車圖、車道與灣區底層。地形、建築、熱區與車輛全在同一 `island-world`，共用 1600 × 1000 座標及鏡頭變換。

## 由你手動預覽

1. 手動開啟 `index.html` → 點西岸海灣 → 觀察約 20 秒，看橘色 720S 經過橘紅橋塔之間的車道；確認勇士入口、道路、橋側步道和碼頭的關係清楚，惡魔島在港外。
2. 選金門大橋：玩家應從勇士入口沿北側道路、橋東端，再走橋側步道到西側觀景點。按「拍一張旅行照」，選舉球、拍照並下載 PNG；實際開啟下載圖片，核對角色、橋、文字與日期。
3. 關閉照片，從「島上偶遇」清單選西岸碼頭步道，再前往潮汐一號。確認沿步道走到碼頭與球場入口，既有政策／球星偶遇／投籃仍可用。
4. 同一構圖切到夜晚，觀察 720S 轉彎時光束隨行進方向轉動；將模擬賽況切為完賽，道路、碼頭與車燈仍亮，主場不再脈動。切到西南沙地觀察黃車，不應有灣區車流在背景偷跑。
5. 手機從「清單 → 美國街景」逐一試四個觀景點。依序核對聖塔莫尼卡碼頭、雲門與自由女神的旅行照與 PNG。確認 16 個其他地標可看名稱，但角色不會被移到未開放入口。
6. 快速連點不同目的地，確認只抵達最後一站；回全島保持玩家位置。切背景再返回，檢查車輛無跳位。開啟系統減少動態後，車輛／路人靜止、玩家直接定位，但所有拍照／遊戲仍可操作。

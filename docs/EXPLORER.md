# 微縮籃球島：鏡頭、步行與日夜

本版只改工作區檔案，沒有開啟瀏覽器／預覽、操作桌面、推送、部署、執行遠端 SQL 或變更 Supabase。直接以瀏覽器開啟根目錄 `index.html` 即可使用；GitHub Pages 的 `/nba-policy-island/` 相對路徑維持相容。畫面與真實裝置的驗收由使用者手動執行。

## 三層視角

- 初次開啟為全島總覽。地景保留不規則海岸、湖泊、高地、沙漠、街廓及擴建預留，新增南北水道、橋面／欄杆、階梯、看台、長椅與樹木。大型室內球館與露天球場仍分開呈現。
- 八個區名或「探索街區」選單可拉近街區。手機總覽只留四個區名，避免標籤密集；選單始終提供全部八區。
- 點地圖或清單中的場地，開啟原有面板並前往入口。移動途中先取景整段道路，抵達後拉近場館。場館的「回街區」保留選取；「回全島」只改鏡頭，角色不回出生點。行走途中手動切鏡頭，抵達時也不會搶回鏡頭。
- 全島只留選取地標與少量模擬 LIVE 主場名稱。街區顯示該區名稱，場館聚焦時保留選取名稱；重疊時優先選取項，再保留 LIVE 名稱。名稱隱藏不影響 aria-label 或完整清單。Tab 聚焦地標會先把入口帶入鏡頭，Enter／空白鍵才前往；區名、工具列與清單使用原生按鈕／選單。

## 行走、偶遇與日夜

角色沿有限道路節點及跨水道橋面行走，最長約 4.2 秒。途中改選會從當下位置取消舊行程，重新走向最新目的地。角色共用儲存後的造型，配短名牌及定位圈；行走中儲存新衣服只更新造型，不瞬移。啟用系統減少動態效果時直接抵達；途中開啟也會立即定位，清除行走計時器。

偶遇點只有在**實際抵達且選取該地點**時，才可能顯示當天的熟悉身影。可點島上的身影或資訊卡角色揭曉，再按「一起拍照」。台灣日期、16 位球星輪替、主場／偶遇兩冊、快照造型與 PNG 匯出沿用原有邏輯。測試日期只在本機 file／localhost 生效：`index.html?encounterDate=2026-01-01` 可固定到碼頭步道遇見柯瑞。公開 Pages 忽略測試參數。

白天／夜晚與模擬賽事是兩個狀態。夜景的路燈、橋欄、碼頭步道、球館窗戶與露天場照明持續亮著，沒有賽事也能辨路；只有模擬 LIVE 的主隊球館脈動。模擬完賽保留比分、停脈動，夜間照明保持。全域夜景不會讓客隊取得「LIVE 主場專屬夜場合影」資格。減少動態效果保留靜態賽事圈與 LIVE 文字。

## 請手動完成的四條動線

1. **全島 → 西岸 → 勇士 → 回街區 → 回全島**：直接開 `index.html`。點「西岸海灣・洛城」或選單西岸，再點勇士；等角色抵達。確認地標外框、造型／短名牌／腳圈、旁邊賽況與尋星／售票入口。按回街區再回全島，角色仍停在勇士，縮放時熱區和建築相符。用 Tab、Enter／空白再做一次。
2. **走到偶遇 → 揭曉 → 收藏 → PNG**：本機使用上面的 2026-01-01 測試網址；從「島上偶遇」清單選西岸碼頭步道。途中不應出現球星；抵達後點島上熟悉身影揭曉柯瑞，按一起拍照、拍照、收藏、下載 PNG。確認照片有雙方造型、地點、文字與日期；換裝後從合影冊「偶遇」查看舊照，維持原樣。主場的柯瑞照片可同時保留。
3. **夜晚 → LIVE → 完賽**：切夜晚，再進湖人主場。勇士為客隊不脈動，湖人有模擬 LIVE 光暈。切已完賽，應保留湖人 101：108 勇士，停止脈動，但道路、橋邊、碼頭及球場照明仍亮。切無賽事也仍有夜景。改為系統減少動態效果，LIVE 顯示靜態圈。
4. **手機清單 → 屋頂 → 遊戲**：手機或自行縮窄視窗，在「玩家球場」清單選霓虹天台，或用場地選單選屋頂區。角色應到霓虹天台入口，面板是「節奏運球」，不是通用投籃。按單人練習，用左右按鈕操作、完成結算、重玩、回球場。其餘四座屋頂場也各自開對應遊戲。確認手機側欄變下方面板、可觸控、無文字裁切。

另請檢查：快速連點不同目的地不會到舊終點；行走途中回全島不會被自動拉回；主場照片相機、勇士政策勾號、金色選取框及 LIVE 圈可分辨。手動下載需確認實際 PNG 像素、字型、手機保存及音效；終端機的 DOM／Canvas 替身測試不能證明這些畫面結果。

## 模組與擴充

- `assets/island-core.js`：沿用 16 隊、15 場、3 偶遇點的 ID／座標與賽事；沒有重命名邀請網址用的球場 ID。
- `assets/explorer-core.js`：八街區、入口、可見路網、最短路徑、鏡頭狀態／有界取景、世界與視窗座標換算、動畫取樣與抵達判斷。新增地標時也須加入所屬街區和道路連結。
- `assets/explorer-ui.js`：共用 world 變換、道路與燈光 SVG、區名、日期身影、日夜按鈕、行走 interval、離場清理與恢復。地形、路網、建築、熱區及角色都在 `#island-world` 內；記分板在鏡頭外保持可讀。
- `assets/explorer.css`：三層名稱密度、獨立夜燈、定位圈及減少動態效果。
- `assets/fan-ui.js`：改讀行走模型位置，實際抵達後才揭曉偶遇；儲存鍵、照片格式、主場合影及 PNG 邏輯保持相容。
- `script.js`：接回原有政策、16 座主場面板、15 款練習／房間入口。

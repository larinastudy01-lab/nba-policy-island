# 夢回 NBA：分階段擴充契約

`journey-franchise-v2` 延續主程式和共用面板。沒有新增套件、後端、遠端 SQL 或新的部署路徑。

| 模組 | 本次可操作範圍 | 後續擴充 |
| --- | --- | --- |
| Explore America | 30 隊城市、橋路網、景點、步行、灣區車道試駕、3D／向量 | 自由轉向駕駛、更多城市生活 NPC、碰撞場景精修 |
| My Franchise | 名稱、城市、幾何隊徽、四種隊色／球衣、球員、球館、理念；建立／編輯／存讀 | 球員培養、招募、交易；未開放能力編輯或真實球員市場 |
| My Island | 獨立第 31 隊島、基礎球場、辦公室、訓練小館、看板、通路 | `BUILDINGS` 中八項未解鎖建設，先等課程公布，再實作成本與取捨 |
| Championship | 選對手、3–5 人陣容、戰術、四回合投籃／封阻、結果／資金／戰績 | 例行賽、季後賽、歷史隊、3v3、真人即時對戰；不做完整 5v5 即時引擎 |
| NBA Time Machine | 七年代氛圍、既有五筆歷史記憶、42 個保留槽及發布驗證契約 | 依 `NBA_HISTORY_JOURNEY_PLAN.md` 查核來源，再把原 15 場逐步改為專屬歷史玩法；目前仍是原 15 款規則 |
| 城市經營 | 六項基準指標與資料契約；對戰僅增加球隊資金 | 決策需有成本、收益、機會成本與多指標影響，不能全部單向加分 |
| 連線 | 保留原公共球場好友房間程式；目前 Supabase URL／公開金鑰皆空 | 不強制後端；連線後另做兩台真機驗證；自創球隊尚未同步至房間 |

儲存界線：新資料只使用 `nba-policy-island:franchise:v1`，版本為 1，保存隊伍、資金、戰績、進行中對戰與六項指標。原造型、合影、政策、商店、地圖和房間邀請鍵不改名。自創隊是 `my-franchise`，島為 `island-my-franchise`，不加入真實 30 隊陣列。新路段只擴充共用道路圖，連接西岸碼頭外側，避開勇士球場。

快速對戰記錄陣容、戰術、共同離線種子、建立時的球隊快照及四回合結果。比分由球員初始能力、戰術與種子產生，命中／封阻再改變比分。它是離線遊戲，不是 NBA 預測或真人賽果。相同對戰 ID 不重複發獎；重新整理後可從原對戰倒數續玩。資金與商店島幣不混用。

`assets/history-contract.js` 提供 42 個 `reserved` 槽，每筆預留年份、年代、球隊／球員、摘要、來源、場景、球場與紀念標記。未查核內容不得發布。Kobe／Gianna 事故追思及其他莊重紀念不連到遊戲，不提供分數或獎勵。既有已查核的記憶資料沿用其事件 ID；不要為多個島入口複製同一事件。

後續 JSON／Fetch／資料庫適配器可替換儲存介面，不應改動純計算模組。任何多人版本需由後端核對成員、局數、種子、開始時間與各自成績，不能信任離線前端獎勵作為真人公平依據。

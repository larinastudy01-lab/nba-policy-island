# 等距像素美術與球衣素材規格

這次只修改本機專案，沒有 push、部署、更動 Supabase，也沒有開啟瀏覽器／預覽或擷取螢幕。公開網站仍維持前一次發佈，待你另行要求更新。

## 共用美術規格

- 現行群島世界為 2560 × 1600，16 隊各有一島；保留原有 15 球場、20 景點、3 偶遇點的 ID 與邀請連結，座標／路網按群島重排。布局來源與三張新預覽見 [ARCHIPELAGO.md](./ARCHIPELAGO.md)。
- 每個地圖像素為 **2 × 2 世界單位**，地面採 **2:1 等距投影**。左上受光、右下陰影。輪廓由整數像素格及水平色段構成，不是只在原向量上套模糊／CSS 濾鏡。
- 地圖使用原生尺寸 PNG／逐格 SVG，`image-rendering: pixelated` 在拉近時保留階梯邊緣。中文介面、資訊卡、比分與地標標籤使用清楚的系統字體，不做像素字體化。
- 道路來源仍是 `ROAD_NODES`／`ROAD_EDGES`。像素道路與互動熱區沿用同一 world 和鏡頭變換；玩家、路人與跑車顯示位置對齊 2 世界單位格，邏輯位置與到達判斷保持原座標。
- 夜景有道路路燈、球館窗光、球場燈、碼頭燈與車燈；模擬 LIVE 主場的脈動另由賽況控制。減少動態時保持靜態光圈及文字。

## 真正不同的模型

| 模型 | 數量與分配 | 可辨識特徵 |
| --- | --- | --- |
| 球館 | 6 種結構，16 隊分配；每隊日／夜各一圖 | 低矮橢圓、圓頂、玻璃立面、鋸齒高頂、多層階梯、紅磚館；不同隊牌與隊色 |
| 社區球場 | 港邊／公園／屋頂 3 套，日／夜共 6 圖 | 貨櫃與護欄；樹蔭、長椅與步道；圍網、設備間與天際線 |
| 美國景點 | 保留 20 種輪廓，日／夜共 40 圖 | 四個拍照點沿用相同地標像素，照片內嵌，不依賴外部圖片 |
| 跑車 | 6 種車身，三視角共 18 圖 | 方尾翼 F40、敞篷 488、眼窩燈 720S、水滴 P1、銳角 Aventador、圓燈 911 |
| 模擬路人 | 8 種模型，配置於原有 10 位路人 | 矮個帽子、高個捲髮、背包、馬尾、連帽衣、銀髮拐杖、抱球、坐姿 |
| 街區小物 | 9 種 | 救生圈、纜樁、長椅、飲水台、排隊欄、貨櫃、花台、路燈、斑馬線 |
| 玩家 | 1 名中性運動服像素球迷 | 與路人一致比例；八方向站立及走路，獨立上身服裝圖層 |

六種球館分配集中在 `assets/pixel-core.js` 的 `ARENAS`；不用修改球隊 ID。15 場仍使用原有小遊戲。六車保留原 ID、四台停放／兩台巡遊；環線與停放點已重排到群島道路，車道不加入步行圖。

## 供你製作球衣的圖格

| 項目 | 規格 |
| --- | --- |
| 單格 | 16 × 24 px，透明 RGBA，禁止抗鋸齒、模糊或邊緣漸層 |
| 完整精靈表 | 80 × 192 px，5 欄 × 8 列 |
| 方向列，由上到下 | 東 e、東南 se、南 s、西南 sw、西 w、西北 nw、北 n、東北 ne |
| 欄，由左到右 | idle、walk-0、walk-1、walk-2、walk-3 |
| 動畫 | 站立固定第 0 欄；走路四幀循環，每幀 150ms；停止立即回 idle |
| 腳底錨點 | 每格 `(8,22)`；所有幀保持相同錨點 |
| 上衣左上對齊點 | 每格 `(4,10)`，上身區域 9 × 7 px（含袖子） |
| 胸前參考點 | `(8,13)`；正面背號／標誌的建議中心，背面另畫 |
| 素材位置 | `assets/pixel/player/body-sheet.png`、`top-neutral-sheet.png`，另附相同 SVG |
| 圖層順序 | 身體／腿／皮膚 → 上衣 → 籃球或手持物；上衣不烘進角色底圖 |
| 像素比例 | 原尺寸作畫，放大只使用 nearest neighbor；遊戲每像素對應 2 世界單位 |

請先複製 `top-neutral-sheet.png` 作為球衣範本，逐格替換中性上衣，保留透明區與相同腳底／對齊點。此版**沒有製作或接入 16 隊玩家球衣**；原有隊色與背號欄位保留為未來設定，玩家先穿中性運動服。球星的隊色屬代表人物插畫，不是玩家球衣系統。

「我的球迷」繼續提供暱稱、膚色、髮型與配件預覽／儲存。新拍的照片帶 `artVersion: pixel-v1`，像素人物與像素背景一起定格；沒有此標記的舊照片繼續用舊渲染器，保存原始造型與構圖。localStorage 的鍵及相簿容器版本不變。

## 原始碼與重建

本次修改：`index.html`、`script.js`、`.gitignore`；`assets/island-core.js`、`sights-core.js`、`bay-scene.js`、`explorer-core.js`、`explorer-ui.js`、`fan-core.js`、`fan-ui.js`、`generate_fan_assets.cjs`。新增下列像素模組／產生器、`assets/pixel/`（130 PNG、162 SVG、1 manifest）、`pixel-tiles.js` 與六張離線比對圖。

測試修改 `tests/check-static.py`、`encounter.test.cjs`、`ui.test.cjs`，新增 `pixel.test.cjs`；文件更新 README、素材 README、CLASSROOM、EXPLORER、SCENERY、FAN_GUIDE 與本頁。

- `assets/pixel-core.js`：整數繪圖、六館／三球場、人物身體／上衣、八方向與圖格規格。
- `assets/generate_pixel_assets.cjs`：以既有隊伍／路網產生圖塊來源、精靈表與小物件。
- `assets/pixel_raster.py`：本專案 SVG 子集的離線整數格光柵器，僅 Python 標準函式庫，不載入網路資源。
- `assets/generate_pixels.py`：輸出 `assets/pixel/` 的 PNG、逐格 SVG、`manifest.json`，以及照片內嵌資料 `pixel-tiles.js`。原先的向量素材保留為來源與舊照片渲染資產。
- `assets/pixel.css`：地圖像素顯示、日夜、中文標籤對比、人物腳底及減少動態。
- `script.js`、`explorer-ui.js`、`bay-scene.js`、`fan-core.js`、`fan-ui.js`：共用地圖模型、八方向人物幀、版本化照片與原有入口。

從根目錄重建：

```powershell
python assets/generate_pixels.py
node assets/generate_fan_assets.cjs
node --test tests/*.test.cjs
python tests/check-static.py
```

網站執行不需要 Python、套件、伺服器或 API Key。

## 離線畫面比對與待驗

現行群島版實測：`node --test tests/*.test.cjs` **198 項通過、0 失敗**；34 個 JS／CJS 檔語法通過。靜態檢查涵蓋 270 個唯一 HTML ID、9 份 CSS、130 組 PNG／SVG 的原始尺寸、CRC、解壓資料長度及整數像素格。原有 34 站與 20 景點的 ID、球場／遊戲配對保留；座標、路網及六車的停放／兩條巡遊路線已重排到球隊群島。

已驗證六種球館與八種路人的實際非透明輪廓都不同；六款跑車的像素剪影也不同。八方向各有四種不同走路像素，停止／減少動態時回站立。原有比分、售票、投籃、每日偶遇、收藏與 PNG 下載協定回歸通過。PNG 的真實瀏覽器輸出與雙裝置好友仍待驗。

初次像素版曾以舊渲染器比對主場、夜場、偶遇、景點四種向量照片的 SVG 逐字相同。本次持續通過舊照片讀回、兩類收藏並存及快照造型不變的回歸測試。

請手動開啟 `index.html`，依序確認：

1. 全島白天 → 西岸拉近 → 勇士主場 → 回街區 → 回全島；角色原位保留，入口與名稱不互相遮擋。
2. 走路途中連點另一站；人物轉向及走路幀切換，到達後停止。啟用減少動態應直接定位。
3. 同構圖切夜景，確認街燈、場線、窗光及車燈；模擬完賽後僅停止主場脈動。
4. 點湖人看比分；勇士試算學生保留席 2,400 點；潮汐一號完成一局投籃，再抽測屋頂節奏運球。
5. 四個景點拍照、下載 PNG；主場找柯瑞與每日偶遇照也要測。查看舊合影仍是舊畫風，新拍照為像素風，換裝不改收藏快照。
6. 手機清單、Tab／Enter／空白鍵、PNG 中文字型／存檔、音效與好友雙裝置連線均需實機確認。Supabase 未配置時不產生假房間。

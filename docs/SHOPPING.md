# 球隊周邊商店與 W12 購物車

勇士島與湖人島主場旁各有一間原創等距像素商店。店面取代該處原有裝飾店屋，店門接上球館旁步道與跨海路網。第一次點店面先走到店門，抵達後可再點店面／按 Enter 或空白鍵，或用資訊面板的「進入店鋪」。主場面板也提供「逛主場旁的周邊店」入口。

兩店共用一台購物車，關閉商店、跨橋、換島都不會清空。工具列「購物車」可隨時查看購物項目、餘額與收藏；加入商品須先抵達相應店鋪。全島總覽不增加店名標籤，拉近當前島才顯示店名，Tab 聚焦可定位店面。

初次建立購物資料發放 **1,200 測試島幣**。可在 `assets/shop-config.js` 設定 `initialCoins`，必須為非負整數。這只影響尚未建立購物資料的新玩家；重新整理或修改設定不會補幣或重設已儲存餘額。

商店和結帳清楚標示「島幣模擬結帳」，沒有真實付款、金流、信用卡欄位或遠端交易。商品價錢是本專案的展示設定，不代表現實周邊售價。

商品已預留 `type: 'jersey'`、`assetId` 與 `available: false` 的兩隊球衣資料，沒有售價，也不出現在販售選單。待使用者完成球衣素材再接入。原有玩家中性上衣與身體圖層、16 × 24 圖格／八方向／上衣對齊點 (4,10) 保持不變。

## W12 表單、事件委派與驗證

- 選商品／數量後，以 `shop-add-form` 的 **submit** 處理加入，`preventDefault()` 防止重新整理。
- 購物車動態列使用 `data-cart-action="update|remove"` 與商品 ID。**只在 `shop-cart-items` 容器綁定一次 click、input、change**，以 `event.target.closest(...)` 找到按鈕，並檢查 `container.contains(...)`。點到按鈕裡的 span 仍可正確委派；重建商品列不重複綁定。
- 數量須為 **1–99 正整數**，拒絕空白、0、負數、小數、科學記號及超量。有效輸入即時更新小計、總額及儲存；「套用數量」也可明確提交。無效輸入保留畫面，資料仍使用上一個有效值，修正前禁止結帳。
- 刪除只移除該商品；清空只清購物車，均不改餘額／收藏。相同商品再次加入會合併數量，兩隊不同商品各自成列。
- **`shop-checkout-form` 的 submit** 先核對畫面數量是否有效且已套用，再由核心驗證購物車、商品、數量及餘額。餘額不足會顯示所需／現有／差額，保留全部資料。
- 成功時在副本計算扣幣、累加收藏、清空購物車，再把整份快照一次寫入 localStorage；只有寫入成功才套用。寫入失敗不扣幣、不增加收藏、不清車，重試不會重複扣款。連續送出成功後，第二次因空車而拒絕。

本次工作區沒有找到所提的 `final_project.html`、`task05_delegation.html` 或 W12 壓縮附件，故尚未逐份比對範例；上述是依需求實作的原生事件委派／submit 流程。提供檔案路徑後才能核對附件的具體編排。

## 儲存與收藏／裝備分離

新鍵為 `nba-policy-island:shop:v1`，同一份 JSON 保存：

```text
version, revision, initialGrant, balance, purchases,
cart: [{productId, quantity}],
collection: [{productId, quantity}],
equipment: {類型: 商品ID}
```

價格與商品名稱只從本地商品資料讀取，不採用儲存內容的價格。收藏保留買過的商品與件數，`equipment` 是獨立狀態；本版沒有裝備按鈕，也不會因購買而修改球迷服裝。

購物資料不共用既有球迷、合影、記憶簿、政策或房間鍵。儲存不可用時可先在本頁調整購物車，但會明確提示，且不回報成功交易；無法讀取既有購物資料時暫停交易、不自動覆寫或再次發幣。偵測另一頁更新過快照時會拒絕覆寫並請使用者重新整理。這仍是瀏覽器本機模擬資料，不是伺服器交易帳本。

## 手動驗收（尚待瀏覽器目視）

1. 本機開 `index.html`。前往勇士主場，按「逛主場旁的周邊店」；確認角色沿步道抵達，店門按 Enter／空白鍵或滑鼠可開啟商店。選勇士帽子 1 件加入，總額 120。
2. 關閉或在商店按「前往湖人紫金周邊店」，看角色沿跨海橋抵達。進店加入湖人迷你籃球 1 件；購物車同時有兩隊商品，總額 **280**，尚未扣款。
3. 點刪除按鈕文字（含內部 span），確認只刪一項；修改數量即時改總額。清空後餘額／收藏不變。重建上述兩項購物車。
4. 輸入 0／小數等無效數量並結帳，確認具體提示、餘額不變。以新帳本預設 1,200 島幣測不足：勇士帽改為 11 件，再加湖人球，共需 1,480、差 280；失敗後仍保留兩項及原餘額。
5. 勇士帽改回 1、湖人球維持 1，送出「島幣模擬結帳」。新帳本應扣 **280**、餘額 **920**、收藏兩隊商品且購物車清空。若已有購買紀錄，依目前餘額計算，不會重發測試幣。
6. 重新整理，工具列開購物車查看收藏與餘額仍在；球迷造型沒有被自動換裝。再試跨島、小遊戲、政策與合影入口。
7. 手機直向／橫向、200% 放大、鍵盤 Tab／Shift+Tab／Escape：確認店門熱區／入口、表單標籤、捲動、商品圖與總額可讀；白天／夜晚店面皆可辨識。

本次不開啟瀏覽器或無頭瀏覽器、不推送、不部署、不修改 Supabase。終端機的 DOM／事件替身不等於真實字體排版、觸控或瀏覽器存檔實測。
